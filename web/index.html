Kualitas terbaik

Otomatis pilih resolusi tertinggi yang tersedia (sampai 4K) dan merge audio + video lewat ffmpeg.

Privasi

Self-hosted di VPS Anda sendiri. File otomatis dihapus setelah TTL berakhir, tidak ada data yang disimpan permanen.

Dibangun dengan Express + yt-dlp + ffmpeg. GitHub
